Show a toast when

  • A new conflict is recorded. Conflicts that arrive within 60 s are batched into one toast.
  • A workspace enters Needs attention, or the reason changes to a new one.
  • A workspace leaves Needs attention, and only if its start was toasted.

Never toast

  • Going offline or back online. The tray and window say it calmly.
  • Saving, sharing as draft, finishing up or publishing.
  • The same workspace + reason again within 30 min, even if it clears and returns. The tray still updates.
  • While Windows Do not disturb / Focus is on. Toasts land quietly in the notification center.

Toast text uses the engine's reason in plain words. No credentials, raw Git output or provider responses, ever.
