### Prompt

I want to have an orchestrator which steers several subagents until a specific goal is reached.

**Example**  
Prompt: Develop all stories in refinement with an implementation plan until they have a test plan.

The orchestrater then picks the ticket with highest rank and calls the development agent, waits until he finishes and hands it over to the code-review agent. The code-review agent is starting with a new context, uses a higher model and effort. If there are findings he hands it back to the development agent.

He does this loop until all findings are fixed or stops after 3 code reviews. Then he lets the development agent write the implementation plan.

He does that until all stories have a test plan and humans can review them together. I would like to have each feature branch will build on the last one, so that we avoid merge conflicts.
